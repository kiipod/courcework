# Методические рекомендации: извлечение из DOCX

Источник: [оригинал](../../docs/Методичка_по_выполнению_курсовой_работы_6.docx), ОЧУ ВО «Московская международная академия», Москва, 2019.

Полный текст основного тела документа разделён по исходным разделам и приложениям. Таблица глоссария сохранена. Орфография, примеры, повторы и противоречия оригинала не исправлялись. Вёрстка, колонтитулы, автоматические номера страниц и пустые абзацы не воспроизводятся. Это текстовая копия для навигации; внешний вид проверяется по DOCX.

Повторное извлечение: `python3 scripts/extract_methodology.py` из корня проекта. Генерируемые файлы этого каталога вручную не редактировать.
