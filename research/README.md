# Исследование

Тема — «Гендерная идентичность». Текущий формат — самостоятельный анализ опубликованных исследований без привлечения участников. Пригодность открытых наборов данных будет оцениваться при поиске. По предварительно найденным публикациям заполнена [пробная таблица извлечения](literature-pilot.md). Итоговый состав корпуса и результаты анализа предстоит определить.

| Файл | Назначение |
| --- | --- |
| [hypothesis.md](hypothesis.md) | Рабочие цель, задачи, исследовательский вопрос и аналитическое предположение |
| [methods.md](methods.md) | Поиск, отбор и сравнение исследований; условия вторичного анализа |
| [protocol.md](protocol.md) | Протокол версии 1.0: границы, поиск, отбор, единицы учёта и оценка предположения |
| [raw-data.csv](raw-data.csv) | Резерв для подходящих исходных открытых данных; сейчас пуст |
| [data-dictionary.md](data-dictionary.md) | Схема таблицы извлечения и будущих переменных |
| [analysis.md](analysis.md) | План сравнения, обработка в Excel и будущие результаты |

`raw-data.csv` не заполняется вымышленными ответами участников и может остаться пустым, если анализ ограничится публикациями и агрегированными показателями. Извлечённые сведения из статей хранятся в отдельной таблице сравнения, а не выдаются за первичные данные студента. Саму таблицу создаём при начале отбора; её поля описаны в словаре данных.

Для каждого значения фиксируются источник, страница или таблица. Сохраняются русский текст или перевод и ссылки для ознакомления, с честным статусом доступности из РФ. Не хранить персональные данные и не восстанавливать идентичность участников чужих исследований.
