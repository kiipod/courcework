# Словарь данных и таблица сравнения

Статус: схема версии 1.0 подготовлена в пункте 2 плана; записей пока нет. Основной материал — публикации, а не собственные ответы участников. `raw-data.csv` остаётся пустым до обнаружения подходящего открытого набора. Правила отбора и единицы учёта — в [протоколе](protocol.md).

## Планируемые поля таблицы извлечения

| Поле | Значение и правило заполнения |
| --- | --- |
| study_id | Код ST-… отдельного исследования; может быть связан с несколькими публикациями |
| source_id | ID проверенной записи из sources/bibliography.md |
| sample_id | Код SM-… исходной выборки; пересечения отмечаются отдельно |
| sample_overlap | independent_reported / shared / partial_overlap / unclear, с основанием; отсутствие сведений не означает независимость |
| locator | Страница, раздел или номер таблицы для проверки извлечения |
| publication_year | Год публикации, отдельно от периода сбора данных |
| data_collection_period | Период сбора данных авторов либо «не указано» |
| definition | Используемое авторами определение гендерной идентичности |
| approach | Теоретический подход, прямо указанный авторами; собственную классификацию маркировать отдельно |
| design | Дизайн исследования |
| sample | Размер и характеристики исходной выборки; не выборка студента |
| instrument | Методика, версия или адаптация, измеряемый показатель |
| measurement_quality | Указанные сведения о валидности и надёжности; отсутствие отмечать |
| reported_result | Результат авторов с единицами, основанием процента и статистикой, если указаны |
| limitations | Ограничения авторов и отдельно собственная оценка |
| comparability | qualitative_only / numeric_candidate / not_comparable / unclear; указать сравниваемые работы, показатель и основание |

Отсутствие сведений — «не указано», а не ноль. Язык, перевод, ссылки и проверка доступа ведутся в реестре источников. Для переноса в CSV зафиксировать UTF-8, разделитель и десятичный знак.

## Организация таблиц в Excel на этапе анализа

- «Публикации»: одна запись на SRC; реестр источников содержит реквизиты и доступ.
- «Исследования»: одна запись на ST; дизайн и основной материал сравнения.
- «Связи»: SRC ↔ ST ↔ SM с пояснением дублирования и пересечений выборок.
- «Извлечения»: определения, показатели и результаты с ID, местом в тексте, формулировкой автора и отдельным комментарием студента. Разные измерения не сводить в нерасчленённое значение.
- «Сводки»: формулы, числители и знаменатели по уникальным единицам. Число строк «Извлечений» не равно числу исследований.

Это схема будущей книги, не заявление о созданном или заполненном XLSX. Категории уточняются после предварительного чтения с фиксацией изменений до итогового анализа.

## Если найден открытый набор

До расчётов отдельно описать происхождение, версию, условия использования, единицу наблюдения, столбцы, шкалы, допустимые значения и пропуски. Сохранить исходные значения без исправления ради результата; преобразования и производные показатели документировать отдельно. Агрегированная строка исследования не является индивидуальной записью участника.
