Ответ получен при отправке того же текста обычным POST-запросом с полем `txt_inp` в `https://plagiat.ai/check_txt2`. Этот обработчик указан в публичном JavaScript формы.

[Исходный JSON-ответ сервиса](plagiat-ai-response.json) сохранён без изменения. Он содержит успешный статус `ok=true`, поля результатов и возвращённый текст. Сверка показала, что сервис удалил скобки и табуляции — 26 символов. Остальной текст совпадает с отправленным. Серверный счётчик показывает 34 175 символов и 4 360 слов.

## Ограничения достоверности

В [публичном коде сайта](https://plagiat.ai/theme/js/custom.js) функция `loadRLinks` получает массив из `links.json`, перемешивает его с использованием `Math.random()` и вставляет выбранные ссылки в таблицу «Список источников» с подписью «Интернет Free». Эта процедура вызывается после успешного ответа обработчика. Содержательная связь этих ссылок с проверяемым текстом кодом функции не устанавливается.

Показатель «Самоцитирование» в шаблоне интерфейса задан постоянным значением 0 %. В сохранённом ответе отдельного измеренного показателя самоцитирования нет. Поэтому он не включён в таблицу результатов проверки.

SHA-256 прочитанного публичного JavaScript — `71556168c81cce017fb9935a1f4671de380956656e911f6952e635094c74df94`. Код может меняться после даты проверки.

Сохранённый JSON позволяет подтвердить, какие цифры вернул сервис для указанного текста. Верифицированного списка совпадений и оснований вычисления этих процентов в полученных материалах нет. Надёжность измерения оригинальности не подтверждена. Для решения о готовности работы по порогу 90 % требуется проверяемый отчёт с источниками и совпадающими фрагментами. Содержательную переработку следует обосновывать конкретными совпадениями при сверке с первоисточниками.
