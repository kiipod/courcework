# Работа с источниками

- `articles/` — доступные полные тексты научных статей.
- `books/` — доступные книги, главы и сведения об изданиях.
- [bibliography.md](bibliography.md) — единый реестр, статусы проверки и будущий список литературы.

Первые результаты подбора внесены в [реестр](bibliography.md). [Журнал поиска](search-log.md) фиксирует запросы и основания отбора. Сохранять только материалы, которыми можно правомерно пользоваться; если файл недоступен, хранить проверенную запись и ссылку, отмечая отсутствие полного текста. Не присваивать записи статус «прочитано» по одной аннотации.

Рабочее имя файла: `SRC-001_Автор_Год_Краткое-название.pdf` (или исходный доступный формат). ID устойчивый; финальный номер в библиографии назначается отдельно после согласования порядка.

## Примеры работ для ознакомления

28.11.2026 пользователь выбрал для второй редакции только курсовую «Гендерная идентичность». Остальные ранее предложенные примеры исключены из действующего списка по его прямому указанию. Выбранная работа служит ориентиром для структуры и подачи: раскрытие понятия, обсуждение социальных условий, содержательные выводы. Научные положения новой редакции обоснованы источниками из [реестра](bibliography.md), а не текстом примера.

| Ссылка | Сведения и статус проверки 28.11.2026 |
| --- | --- |
| [«Гендерная идентичность»](https://www.bibliofond.ru/view.aspx?id=798191#text) | Курсовая работа по психологии, опубликована на сайте 17.10.2014. Веб-инструмент открыл страницу; прямой HTTP-запрос получил HTML с текстом. Рассмотрены структура, подача понятий, социальных условий и заключение. В научную библиографию не включена |

Русский HTML-текст получен без регистрации и оплаты. Скачивание отдельного Word-файла не проверялось. Доступность из РФ не подтверждена: открытие инструментом не является проверкой из российской сети. Методические требования берутся из документа проекта.
