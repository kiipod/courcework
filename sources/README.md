# Работа с источниками

- `articles/` — доступные полные тексты научных статей.
- `books/` — доступные книги, главы и сведения об изданиях.
- [bibliography.md](bibliography.md) — единый реестр, статусы проверки и будущий список литературы.

Литература пока не подобрана. Сохранять только материалы, которыми можно правомерно пользоваться; если файл недоступен, хранить проверенную запись и ссылку, отмечая отсутствие полного текста. Не присваивать записи статус «прочитано» по одной аннотации.

Рабочее имя файла: `SRC-001_Автор_Год_Краткое-название.pdf` (или исходный доступный формат). ID устойчивый; финальный номер в библиографии назначается отдельно после согласования порядка.
