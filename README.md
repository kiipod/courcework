## Как вести работу

1. Использовать выбранную тему и зафиксированные условия; вопросы из [реестра](requirements/open-questions.md) учитывать по мере необходимости, не останавливая текущую работу из-за отложенных реквизитов.
2. Сформулировать проблему, объект, предмет, цель, задачи и проверяемую гипотезу; согласовать план.
3. Собрать и проверить литературу, подготовить теоретический анализ и дизайн исследования.
4. Сформировать корпус публикаций, выполнить самостоятельный сравнительный анализ; обязательно представить количественную характеристику материала и краткий статистический анализ в начале второй главы. Дополнительную обработку опубликованных результатов в Excel проводить при наличии пригодных сопоставимых данных. Отделять опубликованные результаты от собственных расчётов.
5. Связать выводы с задачами, завершить введение, заключение и аннотацию.
6. Собрать `output/coursework.docx`, проверить оформление, ссылки и содержание по чек-листу.

Предложенная пользователем логика каталогов сохранена. Вместо `requirements/methodology.pdf` используется реально предоставленный DOCX и его Markdown-копия: PDF не предоставлен и не создавался. Финальный DOCX появится при сборке написанной работы.
