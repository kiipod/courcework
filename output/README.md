## Сборка

Из корня проекта запустить `python3 scripts/build_coursework.py`. Скрипт создаёт DOCX из материалов в chapters и appendices, задаёт стили, поля, колонтитул, таблицы и поле автоматического содержания. Затем в Windows PowerShell запустить `.\scripts\update_word.ps1 -Document (Resolve-Path .\output\coursework.docx).Path` в среде, где разрешён запуск локального скрипта. Второй шаг обновляет оглавление в настольном Word, сохраняет файл и проверяет страницы при повторном открытии. Также поля можно обновить в Word вручную. После изменения текста измерения и отчёт требуется обновить.

Для пробной вёрстки выбраны Times New Roman с кириллицей, 14 пт, интервал 1,5, поля 30/10/20/20 мм, отступ 1,25 см, заголовки в обычном регистре и ссылки по автору и году. Это рабочие решения по неоднозначностям методички. Линии на титуле предусмотрены для позднейшего заполнения по реквизитам и образцу кафедры. Студент самостоятельно заполняет титул. Пользователь подтвердил доступ к статьям из РФ и отложил выбор правил подсчёта страниц. Открыты вопросы оформления библиографии и страниц SRC-007. Для проверки итогового файла рекомендован вузовский сервис при бесплатном доступе для студента. По основному тексту получен ответ Plagiat.AI с оригинальностью 75 %. Надёжность результата ограничена способом формирования списка источников. [Отчёт](../research/plagiat-ai-report.md). Проектный порог 90 % остаётся открытым.
